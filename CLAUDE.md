# Проект: сайт

Контекст для Claude. Держи файл коротким и обновляй, когда меняются правила.

## Стек
- Статический сайт: чистые HTML / CSS / JS, без сборки и зависимостей (на машине нет Node, Python и Git).
- Структура: `site/index.html`, `site/css/styles.css`, `site/js/main.js`, `site/assets/`.
- Локальный сервер: `serve.ps1` (PowerShell, порт 3000), конфиг в `.claude/launch.json`.

## Доска идей (brief)
- Пользователь излагает задумку на канвасе: http://localhost:3000/canvas/ (заметки, ссылки-референсы, картинки, решения, вопросы, «не хочу»).
- **В начале работы читай `brief/BOARD.md`** (сводка по разделам) и смотри картинки из `brief/assets/`; полная структура с координатами в `brief/board.json`.
- Раздел «Решения» со статусом «Принято» — обязательные требования. «Не хочу» — анти-референсы, не нарушать. «Вопросы» — задавай пользователю, не придумывай ответы.
- Не правь `brief/*` без просьбы: это файлы пользователя.

## Команды
- Запуск превью: `powershell -ExecutionPolicy Bypass -File serve.ps1` (или preview_start `site`).
- Проверка: открыть http://localhost:3000 и посмотреть консоль браузера на ошибки.

## Правила работы
- Сначала план, потом правки. Для нетривиальных изменений описывай, что и в каких файлах поменяешь.
- Меняй минимум файлов; не добавляй библиотеки без согласования.
- Стили через CSS-переменные в `:root`; тёмная тема через `prefers-color-scheme`.
- Семантичная вёрстка, alt у картинок, адаптив от 360px, без горизонтального скролла.
- После правок проверяй результат в браузере (десктоп и мобильный размер), а не только по коду.
- Не коммить и не публикуй без явной просьбы.
- Сайт публикуется как project-страница GitHub Pages: https://oldded-bc-0h-b00e.github.io/SIte-Portfolio/ . Поэтому все пути в `site/` только относительные (`css/...`, `./`), никаких `/...` от корня.
- Репозиторий: https://github.com/OLDDED-bc-0h-b00e/SIte-Portfolio (ветка `main`). Деплой папки `site/` через GitHub Actions (`.github/workflows/pages.yml`). Git: `C:\Program Files\Git\cmd\git.exe`.
- `brief/` в `.gitignore` и в репозиторий не попадает.

## Определение «готово»
- Страница открывается без ошибок в консоли.
- Вёрстка корректна на 360px и 1280px.
- Изменение проверено глазами в превью.
